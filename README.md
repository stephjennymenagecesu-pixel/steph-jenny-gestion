# Steph & Jenny — vrai PDF partageable

Le bouton « PDF / Partager » génère maintenant un vrai fichier .pdf.
Sur iPhone/iPad, si le partage de fichiers Web est disponible, la feuille de partage iOS s'ouvre directement.
Sinon, le PDF est téléchargé afin de pouvoir l'ouvrir dans Fichiers et le partager.

Toutes les données et corrections précédentes sont conservées.
